# Post Lab Answers — Experiment 02

## 1. Use of a corpus in Python
A **corpus** is a collection of text used for statistics, model training, evaluation, and linguistic lookup (e.g. NLTK `brown`, `stopwords`, or your own `.txt` files).

## 2. Features of a corpus
Size, domain, language(s), annotation (raw / POS / NER), balance across genres, format, and license.

## 3. Text processing techniques
Sentiment analysis, NER, summarization, topic modeling, classification, keyword extraction, lemmatization/stemming, plus tokenization, stopword removal, and POS tagging.
